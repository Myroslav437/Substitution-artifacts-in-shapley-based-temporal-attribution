# Figure scripts for Sections 1–3

Each figure of Sections 1–3 is produced by one script here and written to
`../../_arXiv__Substitution_Artifacts_in_Shapley_Based_Temporal_Attribution/media/`. No number or label is typed by
hand: data-like curves come from units generated by DegradX, constants from DegradX's `configs/declarations.yaml`,
and labels from `_common.LABEL`, which matches the text.

| Script | Figure | Content | Data |
|---|---|---|---|
| `fig_state_bands.py` | Fig. 1 | State bands of A1/A2, monotone vs non-monotone mean component | **Schematic** (analytic shapes, no ticks) |
| `fig_toy_window.py` | Fig. 2 | One window under B1, B-pristine, B2⋆, B3⋆, and the sum of the exact attributions of the reference model | DegradX HUST, generation seed 0, the evaluation window with the largest final degradation state |
| `fig_tab_state_traj.py` | Fig. 3 | TAB-state (population at the same state) against TAB-traj (the unit's own past), at their exact estimands | DegradX HUST training units and the unit of Fig. 2 |
| `fig_eval_design.py` | Fig. 4 | Evaluation design, measured arms and case study | **Diagram** |

## Requirements

- A clone of `github.com/Myroslav437/degradx` checked out at commit `f5bba50`; set `DEGRADX_REPO` to its path.
  The generated units are not committed in DegradX; the scripts regenerate them with DegradX's generator from the
  committed fitted profiles (`artifacts/s09_fit_profiles/profiles/`) and split tables
  (`artifacts/s10_generate_units/tables/`), and assert that every unit's length matches DegradX's table.
- Python with numpy, scipy, scikit-learn, pandas, pyyaml and matplotlib (3.10.8, the version of the DegradX figures).
  DegradX's own style module (`degradx.viz.style`) is applied.

The `null_permuted` channel needs measured charge-time readings that DegradX does not commit; a placeholder pool is
passed, which changes only that null channel. No figure uses it.

## Run

```sh
export DEGRADX_REPO=/path/to/degradx      # at f5bba50
sh run_all.sh
```
