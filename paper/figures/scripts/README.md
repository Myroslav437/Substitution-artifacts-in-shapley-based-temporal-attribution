# Figure scripts

Each figure of the paper is produced by one script here and written to
`../../_arXiv__Substitution_Artifacts_in_Shapley_Based_Temporal_Attribution/media/`. No number or label is typed by
hand: data-like curves come from sequences generated by DegradX, constants from DegradX's `configs/declarations.yaml`,
and labels from `_common.LABEL`, which matches the text. DegradX calls each generated sequence a unit; the code keeps
DegradX's names (`units()`, `GeneratedUnit`), the figures use the paper's terms.

| Script | Figure | Section | Content | Data |
|---|---|---|---|---|
| `fig_state_bands.py` | Fig. 1 | 4 | Bands of A1/A2, monotone vs non-monotone mean component | **Schematic** (analytic shapes, no ticks) |
| `fig_toy_window.py` | Fig. 2 | 5 | One window under B1, B-pristine, B2⋆, B3⋆, and the sum of the exact attributions of the reference model | DegradX HUST, generation seed 0, the evaluation window with the largest final degradation state |
| `fig_tab_state_traj.py` | Fig. 3 | 5 | TAB-state (population at the same state) against TAB-traj (the sequence's own past), at their exact estimands | DegradX HUST training sequences and the sequence of Fig. 2 |
| `fig_eval_design.py` | Fig. 4 | 6 | Evaluation design, measured arms and case study | **Diagram** |
| `fig_substitution_distance.py` | Fig. 5 | 6.2 | Distance of B1 and B-pristine from the population at each degradation state, in within-state standard deviations | DegradX training sequences of all three profiles, generation seed 0. **Descriptive** (input data only, no attribution) |

## Requirements

- A clone of `github.com/Myroslav437/degradx` checked out at commit `f5bba50`; set `DEGRADX_REPO` to its path.
  The generated sequences are not committed in DegradX; the scripts regenerate them with DegradX's generator from the
  committed fitted profiles (`artifacts/s09_fit_profiles/profiles/`) and split tables
  (`artifacts/s10_generate_units/tables/`), and assert that every sequence's length matches DegradX's table.
- Python with numpy, scipy, scikit-learn, pandas, pyyaml and matplotlib (3.10.8, the version of the DegradX figures).
  DegradX's own style module (`degradx.viz.style`) is applied.

The `null_permuted` channel needs measured charge-time readings that DegradX does not commit; a placeholder pool is
passed, which changes only that null channel. No figure uses it.

## Run

```sh
export DEGRADX_REPO=/path/to/degradx      # at f5bba50
sh run_all.sh
```
